# PlaceMux – Disaster Recovery Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on *Disaster Recovery, Chaos Testing & Business Continuity* for PlaceMux Task 24.

The project analyzes recovery performance, backup and restore operations, RTO/RPO compliance, backfill status, outage impact, and continuity of critical reporting.

## Tools Used

* *Microsoft Excel* – Data cleaning and preparation
* *Python (Pandas)* – Data analysis
* *Tableau* – Data visualization and interactive dashboard
* *GitHub* – Project documentation and version control

## Key Analysis

* RTO and RPO performance
* Backup status
* Restore status
* Backfill status
* Recovery status
* Reporting continuity
* Outage analysis
* Source-system recovery performance

## Dashboard

An interactive Tableau dashboard was created to provide a clear view of disaster recovery performance and business continuity.

## Project Outcome

The project provides a structured view of recovery performance and helps identify areas where backup, restoration, backfill, RTO/RPO, or reporting continuity may require attention.
